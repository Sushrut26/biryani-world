# Biryani World

A food site about biryani: regional recipes, the history of the dish, an interactive world map of where each style comes from, the science behind the spices, and quick facts.

The site lives in [`biryani-recipes/`](biryani-recipes). The files at the repo root are the original Next.js starter.

## Pages

- **Recipes:** one page per regional style (Hyderabadi kacchi, Lucknowi, Kolkata, Cape Malay, Mandi, Thalassery and more), with structured recipe data for search engines
- **Varieties:** how the styles differ
- **Map:** an interactive atlas of biryani by region
- **History:** a timeline of how the dish spread
- **Spice science:** what each spice does
- **Facts:** short, shareable facts

## Built with

Next.js (App Router), TypeScript, Tailwind CSS, Framer Motion, Vercel Analytics and Speed Insights. SEO includes a sitemap, robots.txt and Recipe JSON-LD. Photos come from Unsplash.

## Run it locally

```bash
cd biryani-recipes
npm install
npm run dev   # http://localhost:3000
```
